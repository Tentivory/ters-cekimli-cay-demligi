# Ters Çekimli Çay Demliği

> **UYARI:** Bu belge, Uluslararası Ters Yerçekimi Çay Kuruluşu (UTYÇK) tarafından Onaylanmış 9. Seviye Ciddiyet Protokolüdür. Gülmek yasaktır. Gülerseniz çay yukarı değil yanlara kaçar.

## Bu nedir?

Klasik çay demleme yöntemleri yerçekimine kölece bağımlıdır. Biz o köleliği yıktık. Bu yazılım, çayı **aşağı değil yukarı** demler. Fincan tavanda durur. Bardak ters durur. Siz ayağa kalkmazsınız, çay size gelir — tavandan.

## Kurulum

```bash
python3 ters_cekimli_cay.py
```

Başka bir şey kurmayın. Kurarsanız evren düzelir, proje bozulur.

## Bilimsel Temel

Newton yanıldı. Elma ağaçtan düşmedi, ağaç elmadan kaçtı. Bu yazılım o gerçeği çaya uygular.

- Sıcaklık: 100°C'nin *tersi* (yani -100 değil, 001)
- Demleme süresi: 3 dakika ama dakika geriye akar
- Şeker: yukarıdan aşağı değil, aşağıdan yukarı erir

## Kullanım Örneği

Program çalıştığında çay molekülleri tavana tırmanır. Siz sadece izlersiniz. İzlemek ücretsizdir. İçmek için tavana merdiven dayayın.

## Sık Sorulan Ciddi Sorular

**S:** Bu gerçekten çalışıyor mu?  
**C:** Fizikçiler henüz yalanlayamadı. Yalanlayana kadar evettir.

**S:** Çay soğur mu?  
**C:** Soğuk da yukarı gider. Isı kaçacak yer bulamaz.

**S:** Neden Türkçe?  
**C:** Çünkü çay Türkçe konuşur.

## Lisans

Ters-Çekim-Kamusal-Lisansı (TÇKL). İstediğinizi yapın ama çayı aşağı demlemeyin. Aşağı demlemek vatana ihanettir (metaforik).
